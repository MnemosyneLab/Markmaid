# MarkMaid v0.1.4 Plan

## Summary

MarkMaid 0.1.4 adds technical reading and export enhancements:

- Chrome-style closed-tab recovery with `⇧⌘T`
- Per-tab document back/forward history with `⌘[` / `⌘]`
- Offline KaTeX rendering for inline `$...$` and block `$$...$$` formulas
- Standalone HTML export and PDF printing with A4/A5 paper sizes, orientation, and margins

## Scope

- Closed-tab history is in-memory, capped at 20 entries, and restores tab type, path, scroll position, and tab order.
- Document navigation history is per ready document tab, capped at 50 entries, and is not persisted across sessions.
- KaTeX is bundled locally with no CDN dependency. Math preprocessing preserves Comrak's `tagfilter` and unsafe HTML protections, while excluding code and currency expressions.
- Export supports standalone HTML with embedded styles/assets and native PDF printing through a hidden print iframe and `@page` CSS.

## Explicitly Out of Scope

- Markdown editing or saving
- Full-text workspace body search
- Continuous filesystem watching
- Heavy PDF rendering dependencies
- Broad filesystem permissions

## Verification

- Frontend Vitest tests cover tab recovery, navigation history, KaTeX rendering, export configuration, and export failures.
- Rust tests cover safe math preprocessing, code/currency exclusion, HTML export path validation, and existing document rendering behavior.
- `pnpm check` is the complete quality gate: TypeScript, Vitest, Vite build, Rust tests, formatting, and Clippy.
- Manual QA covers closed-tab recovery, navigation boundaries, KaTeX themes and invalid formulas, export configuration, HTML output, and PDF print lifecycle.

All nine implementation tasks and four final verification tasks are complete. The detailed execution record remains in the local `.omo/` workflow directory, which is intentionally ignored and not part of the product repository.
