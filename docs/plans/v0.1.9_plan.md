# MarkMaid v0.1.9 Implementation Plan

## 1. Decision summary

v0.1.9 is a **reading-continuity and localization** release. It builds on the
v0.1.8 engineering foundation (typed IPC, session migration harness, thinner
shell) and ships the user-facing metadata workflows selected for this line:

1. **Favorites** — pin frequently read documents independently of Recents,
   stored only as app metadata;
2. **Favorites in Quick Open and the Command Palette** — discovery and toggle
   without inventing a second search surface;
3. **Bookmarks / highlights / notes** — sidecar annotations that never write
   into Markdown source files, with Command Palette actions;
4. **Bounded persisted reading history** — restore navigation continuity across
   restarts beyond today’s per-tab `scrollTop`; and
5. **Chinese / localized UI** — extract strings and add a Settings preference
   for UI language with English fallback tests.

The release must preserve MarkMaid’s read-only boundary: annotations and
favorites never modify document bytes on disk. Full-text search, backlinks,
Workspace Switcher, and editing remain out of scope.

Apple Developer ID signing and notarization remain outside this plan.

## 2. Release outcomes

v0.1.9 is successful when:

- a user can favorite / unfavorite a ready document from the UI and Command
  Palette; favorites survive restart, stay capped, and never appear as edits to
  the Markdown file;
- Quick Open ranks or sections Favorites distinctly from tabs, workspace path
  matches, and Recents; Command Palette exposes add/remove and open-favorite
  commands without putting file paths into the static command catalog as
  command IDs;
- bookmarks, highlights, and notes are stored as app sidecar metadata keyed by
  stable path identity, degrade safely when the file changes or disappears, and
  are reachable from the Command Palette;
- document visit history (and optionally closed-tab reopen history) persists
  across restarts within documented bounds and cleans up missing files;
- the UI can be shown in English or Simplified Chinese via Settings, including
  Command Palette labels and primary shell chrome, with missing keys falling
  back to English in tests; and
- session migration from v0.1.8 / `version: 1` fixtures upgrades cleanly through
  the v0.1.8 migrator into the new schema version with fixture coverage.

## 3. Product boundary

### In scope

- Persist an ordered, capped Favorites list in the session (or sibling app
  metadata store) using canonical paths only—no document bodies.
- Tab context menu, Command Palette, and optional titlebar / sidebar affordance
  for Toggle Favorite.
- Extend Quick Open item kinds with `"favorite"` and integrate into
  `buildQuickSwitcherItems` without breaking tab → workspace → recent priority
  unless Favorites are given an explicit higher section.
- Sidecar models for:
  - **Bookmarks** — named or automatic positions (path + scrollTop and/or
    heading anchor);
  - **Highlights** — ranged annotations tied to source offsets or heading
    anchors plus a content fingerprint / revision token for staleness;
  - **Notes** — short plain-text notes attached to a path or bookmark, stored
    only in app metadata.
- Command Palette commands to add/remove bookmark, jump to bookmark, open notes
  for the active document, and clear stale annotations for the active path.
- Persist a bounded `documentVisitHistory` (and bounded `closedTabsHistory` if
  product chooses both) across sessions; restore Back/Forward continuity where
  still valid.
- String catalog extraction for user-visible TypeScript UI strings and native
  menu labels that are practical to localize in this release; Settings control
  for `uiLocale: "system" | "en" | "zh-Hans"` (exact union may use `zh-CN`
  naming—pick one and keep it stable).
- Schema bump via the v0.1.8 migration harness (`version: 1` → `version: 2` or
  documented equivalent).

### Explicitly out of scope

- Writing favorites, bookmarks, highlights, or notes into Markdown, HTML
  comments, front matter, or sibling `.md` files in the workspace.
- Syncing annotations via iCloud / git / third-party services.
- Full-text body search, backlinks, broken-link reports, or wikilinks.
- Workspace Switcher (named pinned-root sets)—still a later candidate.
- Built-in Markdown editing, continuous filesystem watching, or auto-reload
  beyond existing focus/tab Reload–Ignore behavior.
- Complete localization of every native error string from macOS APIs; privacy
  diagnostics remain code-based where already designed.
- Additional locales beyond English + Simplified Chinese in this release.
- Graph views, daily notes, or Obsidian-compatible vault formats.
- Developer ID signing, notarization, or cross-platform support.

## 4. Current-state assessment

| Area | Current state | v0.1.9 implication |
| --- | --- | --- |
| Recents | `recentDocuments: string[]` max 10, persisted | Favorites are a separate list; never conflate the two |
| Quick Open | kinds `tab` \| `workspace` \| `recent` in `ui-logic.ts` | Add `favorite`; keep path/name matching only |
| Command Palette | Static `CommandId` catalog in `commands.ts` | Add toggle/open commands; do not encode paths as command IDs |
| Scroll | Per-tab `scrollTop` already persisted; visit history runtime-only | Persist bounded visit history; keep per-tab scroll |
| Annotations | None | New sidecar store; never touch file bytes |
| Session | v0.1.8 migrator + `version: 1` | Bump schema; fixture every new field |
| i18n | English literals; `Intl` only for numbers/dates | Catalog + locale preference; fallback tests |
| Shell | Thinner `main.ts` after v0.1.8 | Prefer adding UI in extracted modules / controllers |

## 5. Contracts to establish before implementation

### 5.1 Favorites contract

```text
FavoriteEntry {
  path: canonical absolute path string
  addedAt: number  // epoch ms
}

FavoritesState {
  entries: FavoriteEntry[]  // ordered, unique by path, cap N (suggest 50)
}
```

Rules:

- Favoriting never creates, renames, or writes workspace files.
- Only document-like previews that the product can open (Markdown / Mermaid as
  supported by Open) may be favorited in v0.1.9; images may be included if open
  paths already unify them—document the allowlist once.
- Missing files remain listed until the user removes them or a cleanup pass
  drops entries after a failed open with an actionable notice.
- Toggle Favorite is idempotent; adding an existing favorite may move it to
  most-recent favorite order or leave order stable—pick one and test it.
- Favorites are independent of Recents: opening a favorite may still update
  Recents using existing rules.

Quick Open:

- Include favorites in results with a visible section/label.
- Query matching uses the same path/name rules as other Quick Open sources.
- Activating a favorite opens or focuses the preview through existing open
  paths.

Command Palette:

- `toggleFavorite` enabled when the active tab is a favoritable document.
- Optional `openFavorites…` is **not** a second file search: either jump to
  Quick Open pre-filtered, or list a small recommended subset via a dedicated
  overlay reuse—prefer routing to Quick Open with an initial query/section
  rather than duplicating ranking logic.
- Labels/keywords localized in v0.1.9 catalogs.

### 5.2 Bookmarks / highlights / notes (sidecar) contract

Store annotations in app metadata (session schema or a dedicated store key such
as `annotations-v1` referenced from the session). **Never** write into the
source Markdown file.

```text
AnnotationDocKey = canonical path

Bookmark {
  id: opaque string
  path
  title: user or derived heading string (bounded length)
  scrollTop: number
  fragment?: heading anchor
  createdAt / updatedAt
}

Highlight {
  id
  path
  // Prefer anchor + excerpt fingerprint over fragile absolute offsets alone
  startHint / endHint  // documented strategy: heading id + offset within section,
                       // or UTF-16 offsets + contentHash
  contentHash: short hash of file or section at creation
  colorToken?: limited enum
  createdAt / updatedAt
}

Note {
  id
  path
  body: plain text, max length L (suggest 2–4 KiB)
  bookmarkId?: optional link
  createdAt / updatedAt
}

AnnotationsByPath {
  bookmarks: Bookmark[]
  highlights: Highlight[]
  notes: Note[]
}
```

Rules:

- Caps per path and global caps to protect `markmaid-state.json` size (document
  exact numbers in implementation; suggest ≤50 bookmarks/path, ≤200 global
  highlights, notes body ≤4 KiB).
- On open/reload, if `contentHash` mismatches, mark highlights stale in UI;
  never rewrite the file to “fix” them. User may delete stale items.
- Rendering highlights in preview must be overlay/CSS decoration only, not an
  HTML export mutation unless export explicitly opts in later (default: export
  ignores annotations).
- Notes are private app data; Copy Diagnostics must not include note bodies or
  paths.
- Command Palette: Add Bookmark Here, Show Bookmarks for Document, Add Note,
  Jump to Bookmark (context commands enabled when data exists). Jump commands
  may open a small picker overlay owned by the annotation controller rather
  than stuffing dynamic paths into `CommandId`.

Privacy:

- Paths are stored because the product already persists paths for tabs/recents.
- Note bodies and highlight excerpts stay local; no upload; exclude from
  Copy Details / Copy Diagnostics allowlists.

### 5.3 Persisted reading history contract

Today per-tab `scrollTop` already survives restart. v0.1.9 additionally
persists:

```text
DocumentNavigationEntry { path, scrollTop, fragment? }
// Bounded list + index for Back/Forward

ClosedTab { kind, path, scrollTop, index }  // optional persist; same bound spirit as memory list
```

Rules:

- Bound visit history length (suggest ≤50 entries) and closed-tab history
  (suggest ≤20) on save.
- On restore, drop entries whose paths fail allowlisted existence checks lazily
  (on use) rather than blocking launch with a full filesystem walk.
- Focus Mode remains runtime-only and is not persisted.
- Migration fills empty history for v1 sessions.

### 5.4 Localization contract

```text
UiLocalePreference = "system" | "en" | "zh-Hans"
```

Rules:

- Extract user-visible strings from shell / commands / overlays into a catalog
  module (for example `src/i18n/messages.ts`) with keys stable across releases.
- `system` follows macOS preferred languages with fallback to `en`.
- Missing keys fall back to English; unit tests assert fallback for a
  deliberately missing key.
- Native menus in `src-tauri` that are user-visible should use the same
  preference via a sync at launch / preference change where practical; if a
  subset remains English-only in v0.1.9, document it in the release notes.
- Do not localize document contents, code fences, or user note bodies.
- Command Palette search keywords include locale-appropriate terms (English
  keywords may remain as secondary matches for muscle memory—document the
  choice).
- Persist `uiLocale` in the session schema; changing it re-renders shell chrome
  without reloading the Markdown body if possible (same spirit as Focus Mode
  DOM preservation where feasible).

### 5.5 Session schema bump

Using the v0.1.8 migrator:

- `migrateSession` maps `version: 1` → current (`version: 2`) by adding
  favorites, annotations reference/fields, locale preference, and history
  fields with empty/default values.
- Round-trip fixtures for v1→v2 and native v2.
- Invalid annotation blobs drop to empty with no crash.

## 6. Implementation sequence

1. Confirm v0.1.8 foundations are merged (typed IPC, migrator, shell splits).
2. Schema: add favorites + locale + history fields; migration fixtures first
   (red/green).
3. Favorites state + Toggle UI + Quick Open section + Command Palette commands.
4. Annotation store + preview overlays for highlights + bookmark/note commands.
5. Persist visit / closed-tab history; verify Back/Forward after relaunch.
6. String extraction + `zh-Hans` catalog + Settings language control + fallback
   tests.
7. README, changelog, examples note (annotations never touch source), release
   checklist.

## 7. Testing and QA

### Automated

- Migration fixtures: v1→v2; corrupt annotations; favorite cap; history bounds.
- Quick Open ranking tests including favorites vs recents.
- Command availability tests for toggle favorite / annotation commands.
- i18n fallback tests; locale preference round-trip.
- Privacy tests: diagnostics / Copy Details exclude note bodies and full paths
  as per existing allowlists.

### Manual

- Favorite a file, quit, relaunch; unfavorite; favorite missing file behavior.
- Add bookmark and note; confirm source file bytes unchanged (hash before/after).
- Stale highlight after external edit + Reload.
- Switch UI to Chinese; smoke Command Palette, Settings, empty states; switch
  back to English / System.
- VoiceOver labels still present for new controls.

## 8. Documentation deliverables

- Update [`docs/ROADMAP.md`](../ROADMAP.md) checkboxes for promoted items.
- `CHANGELOG.md` user-facing entries for favorites, annotations, history, i18n.
- `docs/releases/v0.1.9.md` + checklist at ship time.
- README shortcuts / features list; explicit “annotations are app-local” note.

## 9. Risks and mitigations

| Risk | Mitigation |
| --- | --- |
| Highlight offsets break after edits | contentHash + stale UI; prefer heading anchors |
| Store file grows large | Hard caps; optional separate store key; never store document bodies |
| i18n half-coverage looks broken | Prioritize shell + palette + settings; document residual English |
| Palette overloaded with dynamic items | Static commands + small pickers; paths never become CommandIds |
| Scope creep into Workspace Switcher / search | Explicit out of scope; refuse partial search indexes |
