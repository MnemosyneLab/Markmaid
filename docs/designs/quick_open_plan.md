# `⌘P` 检索固定目录中的 Markdown

## 目标与体验

- `⌘P` 保持 Quick Open 定位：仅按 Markdown 的文件名、固定目录名和相对路径匹配，不读取或检索正文内容。
- 每次打开 `⌘P` 时立即显示已打开标签和最近文档，并在后台递归刷新所有固定目录的 Markdown 清单；刷新完成后，非空查询会显示工作区匹配结果。
- 结果顺序固定为：已打开标签 → 固定目录 Markdown → 最近文档；同一路径只出现一次，优先展示已打开标签，其次固定目录结果。
- 工作区结果显示文件名与 `固定目录名 / 相对路径`，并标注为 `Workspace`；`Enter`、鼠标点击均复用现有 Markdown 打开流程。
- 空查询不罗列整个工作区，避免数千文件淹没现有 Quick Open；索引中显示“正在索引固定目录”，完成后提示用户输入关键词搜索。

## 接口与数据流

- 在 `workspace.rs` 新增只读 Tauri 命令 `index_workspace_markdown(root_ids) -> WorkspaceMarkdownIndex`。
  - 返回 `entries: WorkspaceMarkdownEntry[]`，每项包含 `rootId`、`canonicalPath`、`relativePath`、`name`。
  - 返回 `unavailableRootIds`，使单个目录失效、权限变化或读取失败时不阻断其他固定目录的结果。
  - 递归遍历已注册根目录；复用现有 Markdown 扩展名判定，跳过隐藏文件/目录、符号链接、Mermaid、图片和其他文件。
  - 目录扫描放在后台阻塞任务中执行，避免大型目录阻塞 Tauri 前端；扫描结果按根目录与相对路径做稳定、大小写不敏感排序。
  - 根目录只通过已注册 `rootId` 解析；不接受任意文件路径，也不放宽既有根目录边界与符号链接规则。
- 在 `lib.rs` 注册该命令；前端增加对应的 `WorkspaceMarkdownEntry` / `WorkspaceMarkdownIndex` 类型。索引只保存在运行时内存，不写入会话持久化数据。
- Quick Switcher 增加 `workspace` 项类型；`buildQuickSwitcherItems` 接收当前工作区索引和根目录元数据。
  - 使用现有“所有查询词都需匹配”的大小写不敏感规则，匹配 `name + root displayName + relativePath`。
  - 工作区结果仅在存在有效查询词时加入；同名文件通过详情路径区分。
  - 工作区结果按“文件名完全匹配、文件名开头匹配、其余路径匹配”排序，再按路径稳定排序；最多渲染前 200 条，并提示继续输入以缩小范围。
- `openQuickSwitcher()` 每次创建新的索引请求序号、清空旧工作区索引并异步调用索引命令。只有对当前仍打开的命令框、且请求序号仍有效的响应可以更新结果。
  - 固定目录新增、移除、创建、重命名、移入废纸篓时使当前索引请求失效；若命令框仍打开，立即重新索引。
  - 索引失败时保留打开标签和最近文档结果，并显示简短的不可用目录提示；不影响现有快捷键、焦点、方向键、Esc 与 Enter 行为。
  - 激活 `workspace` 结果时复用 `openDocumentPaths([canonicalPath])`，因此继续使用现有的标签去重、预览、最近文档和错误提示逻辑。

## UI 与文档

- 更新 Quick Open 的输入标签、占位符与空状态，使其明确会搜索“open tabs, pinned Markdown files, and recent documents”。
- 为索引中、无匹配、部分目录不可用、结果被 200 条上限截断分别提供简短状态文案；不新增持续文件监听或手动刷新按钮。
- 更新 README 的功能说明和快捷键说明：`⌘P` 可递归搜索固定目录中的 Markdown；明确它不搜索正文、不包含 `.mmd` 或图片，并且在每次打开时刷新。

## 测试与验收

- Vitest 覆盖：
  - 空查询只保留现有标签与最近文档。
  - 多关键词可命中文件名、根目录名和嵌套相对路径。
  - 工作区候选项排在最近文档前，并与已打开/最近的同路径项去重。
  - 同名文件显示可区分路径，排序和 200 条截断稳定。
- Rust 单测覆盖：
  - 递归发现 `.md`、`.markdown`、`.mdown`、`.mkd` 及大小写变体。
  - 排除隐藏项、符号链接、图片、Mermaid 和不支持的普通文件。
  - 一个固定目录读取失败时返回其他目录结果及不可用根目录标记。
  - 未注册根目录、路径边界和重复/嵌套根目录不会产生越界或重复候选。
- 手工验收：
  - 在固定目录深层新增 Markdown 后，关闭并重新打开 `⌘P` 可被检索到。
  - 双固定目录含同名 Markdown 时，可凭目录详情区分并打开正确文件。
  - 删除或重命名发生在命令框打开期间不会让过期异步结果重新出现。
  - 没有固定目录时，`⌘P` 行为与当前版本完全一致。
- 完成后执行 `pnpm check`，确保前端单测、TypeScript 构建、Rust 单测、格式化和 Clippy 都通过。

## 默认约束

- 不搜索 Markdown 正文，不增加全文索引、数据库或文件监听。
- 不改变固定目录树支持的文件类型；本功能只向 `⌘P` 暴露 Markdown。
- 不触碰当前无关的 `src/styles.css` 本地修改。
