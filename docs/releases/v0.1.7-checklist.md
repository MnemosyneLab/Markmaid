# MarkMaid v0.1.7 Release Checklist

This is the mutable release-signoff record for v0.1.7. Public-facing copy lives
in [`v0.1.7.md`](v0.1.7.md). Do not tag or publish until every artifact gate and
required manual QA item is complete.

## Implementation and automated preparation

- [x] Typed Command Palette catalog/controller, `⇧⌘P` native/frontend routing,
  disabled reasons, focus trap, and `⌘P` Quick Open separation implemented.
- [x] Runtime-only Focus Mode model, DOM-preserving toggle, `⇧⌘F` native/frontend
  routing, Escape priority, content focus fallback, and non-persistence tests
  implemented.
- [x] Actionable empty/workspace/preview/Quick Open/export/external states and
  allowlisted Copy Details formatter implemented and unit tested.
- [x] Bounded macOS application discovery, icon conversion, target revalidation,
  Finder/terminal adapters, typed errors, and safe open tests implemented.
- [x] External chooser controller, preferred-target split button, Command Palette
  and tab-context commands, session-v1 compatibility, unavailable preference,
  and successful-open persistence behavior implemented.
- [x] Deterministic fixtures, structural performance smoke gate, explicit
  frontend/native release baseline runner, and initial baseline document added.
- [x] README, dated changelog, Roadmap, public release notes, performance notes,
  and this mutable checklist updated for the implemented scope.
- [ ] Version metadata synchronized at `0.1.7` in npm, Tauri, Cargo manifest,
  Cargo lock metadata, and release configuration.
- [ ] Final `CI=true pnpm check` passes from the release-preparation tree; record
  frontend/Rust test counts and production-build result here.
- [ ] Apple Silicon debug `.app` build passes; confirm bundle version and Mach-O
  arm64 architecture.

## Manual application QA

- [ ] Open Command Palette from top-tab, left-tab, empty, ready, error, and
  Settings states. Verify search ranking, disabled reasons, pointer selection,
  keyboard navigation, IME composition, focus restoration, and execution errors.
- [ ] Confirm `⌘P` remains Quick Open and `⇧⌘P` remains Command Palette in both
  native menus and WebView focus contexts; verify export/Find/tab shortcuts.
- [ ] Enter and exit Focus Mode using `⇧⌘F`, View menu, Command Palette, Exit
  button, and Escape after closing viewers/dialogs/menus/Quick Open/Find.
- [ ] In Focus Mode verify tabs, sidebars, outline, ordinary titlebar actions,
  and normal status are absent from keyboard/VoiceOver navigation; transient
  notices, drag/drop, external-change alerts, export, and print still work.
- [ ] Restart while Focus Mode is active and confirm it starts off while saved
  sidebar, outline, tab placement, theme, scroll, and workspace preferences
  restore unchanged.
- [ ] Exercise every actionable state: no roots, roots/no tabs, empty root and
  folder, unavailable root, preview error, failed/truncated Quick Open index,
  export failure, and external launch failure.
- [ ] Copy Details from representative failures and confirm it contains only app
  version, area, normalized code/state, and recoverability—no path, filename,
  content, raw message, query, app inventory, or icon data.
- [ ] External chooser: no preference, System Default, Finder, at least two
  installed handlers, supported terminals, preference checkmark/restart, app
  uninstall/reinstall, Refresh, opening failure, and active-tab switch.
- [ ] Verify external opening never closes the MarkMaid tab, changes history,
  reads document contents, broadens asset scope, or starts file watching.
- [ ] Verify keyboard-only use, VoiceOver roles/names/announcements, 200% zoom,
  all appearance palettes, reduced motion, and reduced transparency.
- [ ] Re-run v0.1.6 regression paths for pinned-root reorder, diagnostics,
  cancellation, Files tree, viewers, session restore, reload failure, local
  asset bounds, HTML/PDF export, and print-window cleanup.

## Performance and artifact gates

- [x] `CI=true pnpm perf:smoke` passes with no wall-clock assertions and the
  committed fixture fingerprint matches two regenerations.
- [x] `pnpm perf:baseline` produces ignored privacy-safe frontend and native JSON
  reports; captured median/p95 values are recorded in the performance document.
- [ ] Review a second clean baseline capture before accepting any regression
  budget; keep timing thresholds outside normal CI.
- [ ] Commit and push the final implementation/version/documentation tree;
  confirm `main` is clean and synchronized with `origin/main`.
- [ ] Run `CI=true pnpm release:build` from the final clean pushed commit.
- [ ] Confirm `artifacts/v0.1.7/` contains exactly the arm64 DMG, app ZIP, and
  `SHA256SUMS`; validate versions, ad-hoc signature, bundle integrity, DMG, ZIP,
  architecture, and checksums.
- [ ] Run `CI=true pnpm release:publish -- --dry-run`; confirm tag target, release
  notes, compare link, asset names, and checksums.
- [ ] Publish v0.1.7 only after signoff, then verify the annotated tag, GitHub
  Release body, all assets, and displayed checksums.

Apple Developer ID signing and notarization remain intentionally out of scope.
