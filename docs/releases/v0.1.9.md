# MarkMaid v0.1.9

MarkMaid v0.1.9 is a reading-continuity and localization release. It adds
Favorites, app-local bookmarks/highlights/notes, persisted visit and closed-tab
history, and English / Simplified Chinese UI. It does not add search, editing,
or Workspace Switcher.

## Highlights

- Pin ready Markdown and standalone Mermaid documents as Favorites. They appear
  in Quick Open after open tabs and before workspace/recents, and can be opened
  from a Favorites-only Quick Open scope.
- Add bookmarks, Find-based highlights, and short notes without writing Markdown
  source. Annotations live in `markmaid-annotations.json` with per-document and
  global caps.
- Restore bounded document visit history and closed-tab history after relaunch.
  Reopen Closed Tab peeks first and consumes the entry only after a ready
  preview.
- Switch the UI between English, Simplified Chinese, or the macOS preferred
  languages. Traditional Chinese does not convert automatically. Locale changes
  keep the current preview DOM attached.
- Session restore uses version 2. v0.1.8 sessions migrate in place. A newer
  unsupported session version is opened read-only so it is not overwritten.

## Compatibility and non-goals

MarkMaid remains preview-first and read-only. Annotations never enter Markdown,
HTML comments, front matter, HTML/PDF export, or diagnostics. Favorites accept
only ready Markdown and standalone Mermaid files.

This release does not add Workspace Switcher, full-text search, backlinks,
editing, continuous filesystem watching, extra locales, Developer ID signing, or
notarization.

## Installation

MarkMaid is currently distributed for Apple Silicon Macs. Download either the
DMG or app ZIP from the GitHub Release.

Current builds use an ad-hoc signature rather than Developer ID signing and
notarization. After copying MarkMaid to `/Applications`, clear the quarantine
attribute if macOS blocks the app:

```sh
xattr -cr /Applications/MarkMaid.app
```
