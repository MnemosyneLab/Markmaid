# MarkMaid v0.1.5

MarkMaid v0.1.5 is a reliability and safety release for the read-only local
document workspace. It makes preview opening consistent across the app, keeps
background work from disrupting the active document, and bounds expensive file
and workspace operations.

## Highlights

- Open Markdown, standalone Mermaid, and common image files through the Open
  dialog, drag and drop, Finder, forwarded app instances, Markdown links, or the
  Files sidebar.
- Navigate one global Back / Forward history across tabs, relative links,
  anchors, restored sessions, and reopened documents.
- Keep background loads and reloads from stealing the active tab, while safely
  ignoring stale results after retries or tab closure.
- Re-render every open standalone Mermaid preview when its theme changes,
  including files outside pinned folders.
- Keep large workspaces responsive with bounded directory visibility scans and
  Quick Open indexing. Truncated and unavailable roots are reported separately.
- Harden native PDF printing with a page-load watchdog, bounded print-panel
  interaction, one-shot cleanup, and a dedicated minimal Tauri capability.

## Safety and limits

- Markdown and standalone Mermaid previews are limited to 16 MiB per file.
- Direct image previews are limited to 100 MiB per file.
- Hidden entries, symlinks, and common generated directories such as `.git`,
  `node_modules`, `dist`, `build`, `target`, `.venv`, and `Pods` are excluded
  from workspace traversal and Quick Open indexing.
- Local image access is limited to explicitly opened images, a document's
  directory subtree, or the shared pinned workspace root containing the
  document. Grants last for the current app session.
- Quick Open continues to index file names and paths for Markdown files only;
  it does not search document contents, Mermaid files, or images.

## Installation

MarkMaid is currently distributed for Apple Silicon Macs. Download either the
DMG or app ZIP from the GitHub Release.

Current builds use an ad-hoc signature rather than Developer ID notarization.
After copying MarkMaid to `/Applications`, clear the quarantine attribute if
macOS blocks the app:

```sh
xattr -cr /Applications/MarkMaid.app
```

MarkMaid remains preview-first and read-only. This release does not add a
Markdown editor or continuous filesystem watching.
