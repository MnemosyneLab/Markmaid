## Manual application QA

- [x] Reorder 1, 2, and 10+ pinned roots by drag handle and Move Up / Move Down;
  verify disabled boundaries, focus restoration, announcements, restart
  persistence, expansion state, and Quick Open tie-break behavior.
- [x] Copy Diagnostics in normal, loading, and representative error states;
  verify the 0.1.6 version/counts and confirm that no source, HTML/SVG, filenames,
  full paths, recents, queries, clipboard contents, or raw errors appear.
- [x] Rapidly open, close, retry, reload, and supersede Markdown, Mermaid, and
  image previews; repeatedly change Mermaid themes and open/close Quick Open;
  confirm cancellation stays silent and useful sibling results still load.
- [x] Collapse and remove roots during uncached child listing; confirm no stale
  children, notices, or leaked native task entries appear.
- [x] Traverse the app using keyboard only, including Files tree arrows,
  `Shift+F10` context menus, tab lists, sidebar tabs, dialogs, Quick Open, export,
  viewers, and the resize separator.
- [x] With VoiceOver, verify roles, names, levels, selected/expanded state,
  status announcements, modal focus traps, Escape behavior, and deterministic
  focus fallback after closing or reordering roots and tabs.
- [x] Verify 200% zoom, high-contrast palettes, reduced motion, and reduced
  transparency without clipped critical controls.
- [x] Re-run v0.1.5 regression paths: dialog/drag/Finder/forwarded opening,
  relative links and history, lazy restore, reload failure, local asset bounds,
  HTML export, native PDF success/cancel/failure, and print-window cleanup.
