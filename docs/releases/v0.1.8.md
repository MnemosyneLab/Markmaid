# MarkMaid v0.1.8

MarkMaid v0.1.8 is an engineering-foundation release for the read-only local
document workspace. It adds no new reading workflow. It hardens the typed
frontend ↔ Rust command contract, session restore, and shell structure that
v0.1.9's persisted reading metadata and localization work will use.

## Highlights

- A single Specta registry generates the TypeScript contract for all 25 Rust
  commands and all 26 frontend call sites, with committed output and a
  deterministic `ipc:check` drift gate.
- Frontend native calls use the generated command catalog and shared typed
  result handling. Raw `invoke` remains only in generated output.
- Session-v1 restore now runs through a pure migration and normalization
  pipeline with fixture-driven coverage. Invalid values fall back to defaults.
  Store-open and Store-write failures show one privacy-safe notice and disable
  persistence for that launch without overwriting an unreadable file.
- Quick Open, Command Palette, workspace tree, Find, Settings/status, export,
  sidebar, external-open, and tab interaction views are isolated from the
  composition root.

## Compatibility and non-goals

The persisted session schema remains exactly version 1. Focus Mode, closed-tab
history, and document visit history stay runtime-only. Existing v0.1.7 sessions
restore normally.

MarkMaid remains preview-first and read-only. This release does not add
Favorites, bookmarks, highlights, notes, persisted reading history, UI
localization, Workspace Switcher, full-text search, editing, continuous
filesystem watching, Developer ID signing, or notarization.

## Installation

MarkMaid is currently distributed for Apple Silicon Macs. Download either the
DMG or app ZIP from the GitHub Release.

Current builds use an ad-hoc signature rather than Developer ID signing and
notarization. After copying MarkMaid to `/Applications`, clear the quarantine
attribute if macOS blocks the app:

```sh
xattr -cr /Applications/MarkMaid.app
```
