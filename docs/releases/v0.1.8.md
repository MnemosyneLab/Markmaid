# MarkMaid v0.1.8

Status: engineering-complete; local artifact signoff and publication remain
separate release operations.

## Theme

v0.1.8 is an engineering-foundation release. It adds no new reading workflow.
It prepares the contracts and seams needed by v0.1.9's persisted reading
metadata and localization work.

## Highlights

- A single Specta registry generates the TypeScript contract for all 25 Rust
  commands and all 26 frontend call sites, with committed output and a
  deterministic drift check.
- Frontend native calls use the generated command catalog and shared typed
  result handling.
- Session-v1 restore now runs through a pure migration and normalization
  pipeline with fixture-driven coverage; Store-open failure is handled at
  bootstrap without overwriting an unreadable file.
- Quick Open, Command Palette, workspace tree, Find, Settings/status, export,
  sidebar, external-open, and tab interaction views are isolated from the
  composition root.

## Compatibility

- The persisted session schema remains exactly version 1.
- Focus Mode, external handoff, export, cancellation, accessibility behavior,
  and existing preview workflows remain in scope for regression verification.
- Apple Silicon ad-hoc signing remains the release policy; Developer ID
  signing and notarization are not part of this version.
