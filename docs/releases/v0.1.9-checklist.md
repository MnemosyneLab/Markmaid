# MarkMaid v0.1.9 release checklist

This checklist is the mutable signoff record. It intentionally separates
engineering completion from local artifact verification and publication.

## Engineering

- [x] All version metadata is `0.1.9`.
- [x] Session-v2 migration, favorites, locale, and persisted history are
  implemented with tests.
- [x] Annotation store, overlay, Find-based highlights, and path lifecycle are
  implemented without writing Markdown source.
- [x] Frontend i18n catalogs and native `set_ui_locale` menu rebuild are in
  place; generated bindings include the new command.
- [x] `src/main.ts` remains a composition root of 4,000 lines or fewer.
- [x] Changelog, roadmap, README, and release notes describe the shipped
  continuity and localization behavior.

## Automated verification

- [x] `CI=true pnpm check`
- [ ] `pnpm release:build`
- [ ] `pnpm release:publish -- --dry-run`
- [ ] ARM64 app, DMG, ZIP, signature, and checksum inspection

## Manual signoff

- [ ] Cold launch migrates a v0.1.8 session to v2 without losing tabs or
  preferences.
- [ ] Unsupported future session version shows one notice and does not overwrite
  the Store.
- [ ] Favorites, Quick Open scope, annotations, Find highlight capture, locale
  switch (preview DOM preserved), rename/Trash metadata, and VoiceOver smoke
  checks pass on Apple Silicon.

## Publication

- [ ] Version change committed and pushed to the release branch.
- [ ] GitHub Release notes reviewed and published.
