# MarkMaid v0.1.8 release checklist

This checklist is the mutable signoff record. It intentionally separates
engineering completion from local artifact verification and publication.

## Engineering

- [x] All version metadata is `0.1.8`.
- [x] Specta command registry and generated TypeScript bindings are committed
  for all 25 registered commands and 26 frontend call sites.
- [x] `pnpm ipc:check` passes after generation.
- [x] Frontend raw `invoke` calls are confined to generated output.
- [x] Session migration and bootstrap Store-failure boundary are implemented
  with tests.
- [x] Required shell views are extracted and `src/main.ts` is at or below
  4,000 lines.
- [x] Changelog, roadmap, README, releasing guide, and release notes are
  updated without claiming new reading features.

## Automated verification

- [ ] `CI=true pnpm check`
- [ ] `pnpm release:build`
- [ ] `pnpm release:publish -- --dry-run`
- [ ] ARM64 app, DMG, ZIP, signature, and checksum inspection

## Manual signoff

- [ ] Cold launch restores a v0.1.7 session without changing persisted schema.
- [ ] Corrupt Store-open fallback shows one safe notice and does not overwrite
  the unreadable file.
- [ ] Quick Open, Command Palette, Focus Mode, export, external open, Files,
  Find, and VoiceOver smoke checks pass on Apple Silicon.

## Publication

- [ ] Version change committed and pushed to the release branch.
- [ ] GitHub Release notes reviewed and published.
