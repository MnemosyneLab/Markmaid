# MarkMaid v0.1.6

MarkMaid v0.1.6 is a workspace-polish and maintainability release for the
read-only local document workspace. It makes pinned folders easier to organize,
adds privacy-safe support information, reduces wasted background work, and
improves keyboard and assistive-technology behavior throughout the app.

## Highlights

- Reorder pinned workspace folders with a dedicated drag handle or the root
  context menu's Move Up / Move Down actions. The order survives restart and is
  used only as a final Quick Open tie-breaker between equally ranked workspace
  results.
- Copy a deterministic diagnostic report from Settings. It includes app/runtime
  details and bounded state counts, but excludes document contents, rendered
  HTML/SVG, filenames, full paths, recent entries, queries, clipboard contents,
  and raw backend errors.
- Cooperatively cancel superseded preview loads and reloads, Mermaid theme
  rerenders, workspace child listing, and Quick Open indexing while retaining
  generation checks that prevent stale results from changing the UI.
- Navigate the Files tree, tab lists, context menus, dialogs, Quick Open, export,
  viewers, and the sidebar resize separator with standard keyboard and focus
  behavior. Root and tab reordering retain non-drag alternatives and audible
  position announcements.
- Split preview, workspace, navigation, overlay, export, persistence, and runtime
  behavior into explicit tested controllers without changing the persisted
  session-v1 format or adopting a frontend framework.

## Privacy, cancellation, and compatibility

- Diagnostics are generated only when Copy Diagnostics is pressed and are copied
  locally. MarkMaid has no telemetry, analytics, crash upload, or automatic
  diagnostic transmission.
- Diagnostic errors retain only a bounded operation identifier and a strict
  normalized error code. Arbitrary error prose is reported as `unknown` rather
  than being transformed into a token that could retain private path segments.
- Cancellation is cooperative and best-effort, not hard thread interruption. A
  Markdown or Mermaid render already inside one non-interruptible library call
  may finish internally, but its result is discarded when it is stale or
  cancelled.
- Pinned-folder reorder changes app state only. It does not reorder files on
  disk, clear child caches, close tabs, or migrate the persisted session schema.
- MarkMaid remains preview-first and read-only. This release does not add
  editing, continuous filesystem watching, full-text search, telemetry, or
  cross-platform support.

## Installation

MarkMaid is currently distributed for Apple Silicon Macs. Download either the
DMG or app ZIP from the GitHub Release.

Current builds use an ad-hoc signature rather than Developer ID signing and
notarization. After copying MarkMaid to `/Applications`, clear the quarantine
attribute if macOS blocks the app:

```sh
xattr -cr /Applications/MarkMaid.app
```
