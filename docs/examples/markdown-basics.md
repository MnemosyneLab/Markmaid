# Markdown basics

A short sample for MarkMaid’s Markdown preview: headings, lists, quotes,
links, and emphasis. Use the outline sidebar to jump between sections.

#### Level four

## Emphasis

- *Italic* with single asterisks
- **Bold** with double asterisks
- ***Bold italic*** combined
- `Inline code` with backticks

## Lists

Unordered:

- Pin a folder in the workspace sidebar
- Expand directories on demand
- Double-click a supported file to open a preview tab

Ordered:

1. Open this document
2. Scroll the preview
3. Try Find with `⌘F` (search for `workspace`)

Nested:

- Workspace
  - Files tree
  - Open Tabs
- Status bar
  - Line / word / character counts
  - Theme and file metadata

## Block quote

> then reload here with `⌘R` when the file changes.
